# Calculatrice Web

## Description

Application web de calcul développée avec Python, Flask
et la programmation orientée objet.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Historique des calculs
- API REST au format JSON

## Installation

Créer un environnement virtuel :

python -m venv .venv

Activer l'environnement sous Windows :

.venv\Scripts\activate

Installer les dépendances :

pip install -r requirements.txt

## Lancement

python app.py

Ouvrir ensuite :

http://127.0.0.1:5000

## API REST

Méthode : POST

Route : /api/v1/calculer

Format : JSON
